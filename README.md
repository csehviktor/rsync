# rsync

A lightweight CLI tool to synchronize local directories with Cloudflare R2 buckets.

---

## Prerequisites

- Rust toolchain
- Cloudflare R2 bucket
- Cloudflare API Tokens 
  - Account ID
  - Access Key ID
  - Secret Access Key

---

## Installation

```bash
git clone git@github.com:csehviktor/rsync.git
cd rsync
cargo build --release
```

### Recommended: Add to PATH

```bash
cargo install --path .
```

## Subcommands

- ``rsync initialize/init``: initialize configuration and state files in the current directory
- ``rsync validate``: verify credentials and test bucket reachability
- ``rsync list/ls``: compare local files against the bucket and show sync status
- ``rsync push``: upload local changes
- ``rsync pull``: download remote changes

> **note:** path under the exclude key, as well as files starting with a dot, including `.config.toml` and `.state.toml`, are automatically ignored during syncing

## Configuration

After initialization, open `.config.toml` and fill in your Cloudflare credentials:

```toml
[credentials]
account_id = "<your-account-id>"
access_key_id = "<your-access-key-id>"
secret_access_key = "<your-secret-access-key>"

[settings]
bucket = "<your-bucket>"
exclude = []
```

> **note:** the `.state.toml` file tracks the SHA-256 hashes of synced files, which the entire syncing process relies on, therefore, DO NOT edit this file
